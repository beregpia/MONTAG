# Как экспортнуть фрагмент

> Дата: 30 октября 2026. Ответ на вопрос «как экспортнуть фрагмент».
> Главное правило: **видео и дорожки фоли должны покрывать один и тот же
> диапазон**, и вы должны знать таймкод, с которого этот диапазон начинается.
> Без этого числа все позиции поедут.

---

## 0. Золотое правило

Движок работает так: `время в WAV = 0` соответствует **какому-то** таймкоду.
Если видео и звук покрывают одинаковый диапазон и вы сказали, с какого ТК он
начинается, — всё сходится. Если нет — расстановка уедет.

Поэтому экспорт — это **два действия над одним и тем же диапазоном**:
1. выгрузить видеофрагмент;
2. выгрузить дорожки фоли за тот же диапазон;
3. запомнить (и передать движку) ТК начала фрагмента и fps.

---

## 1. Считать диапазон (не в уме)

В Pro Tools вы оперируете таймкодом, а HandBrake и ffmpeg — секундами от начала
файла. Мостик уже есть:

```bash
# фрагмент на 60 секунд, начиная с 01:04:12:07, проект 25 к/с, старт сессии 01:00:00:00
node tools/tc.mjs --range 01:04:12:07 01:05:12:07 --fps 25 --start 01:00:00:00
```

Вывод:

```
  начало  252.280 с   (ТК 01:04:12:07)
  конец   312.280 с   (ТК 01:05:12:07)
  длина   60.000 с

  ffmpeg -ss 252.280 -to 312.280 -i movie.mov -c:v libx264 -c:a aac fragment.mp4
  HandBrake: Range → Seconds, с 252.28 по 312.28
```

Если нужен только один момент: `node tools/tc.mjs 01:04:12:07 --fps 25 --start 01:00:00:00`.

> **Проверка допущения:** считается, что кинофайл начинается с `00:00:00:00`,
> а `Session Start` в Pro Tools — это смещение сессии относительно файла.
> Если у вас иначе, скажите — поправлю расчёт.

---

## 2. Экспорт видео — три способа

### Способ А. HandBrake (проще всего, рекомендуется)

Бесплатная программа с окошком, без командной строки: `handbrake.fr`.

1. Открыть HandBrake → **Open Source** → выбрать кинофайл.
2. На панели сверху найти выпадающий список **Range** (по умолчанию «All»).
3. Переключить на **Seconds** и ввести числа из `tools/tc.mjs`:
   `252.28` … `312.28`.
4. Пресет: любой из **Fast 1080p30** — этого достаточно. Контейнер **MP4**,
   видео **H.264**, звук **AAC**.
5. **Не меняйте частоту кадров** — должна остаться родная (25 или 24).
   Если пресет подставляет другую, на вкладке Video поставьте ту же, что в
   проекте, и постоянный frame rate.
6. **Browse** → имя `fragment.mp4` → **Start Encode**.

Готово. Движок откроет такой файл в браузере без конвертации.

### Способ Б. Из самой сессии Pro Tools

1. Сделать **выделение на таймлайне** ровно по нужному диапазону
   (тянуть мышью по линейке, или три точки `…` → Enter и ввести ТК начала и конца).
2. **File → Bounce → QuickTime Movie**.
3. В диалоге указать файл, формат **H.264**, и источником баунса выбрать
   **выделение на таймлайне** (не всю сессию).
4. Encode.

Способ рабочий, но менее предсказуемый: иногда проще ошибиться с диапазоном.
Если баунс всей сессии делать нельзя — HandBrake надёжнее.

### Способ В. Из Resolve / Premiere

Если картинку монтируете там: **In/Out** по диапазону → Deliver/Export →
MP4, H.264, родной fps. Это самый контролируемый путь.

## 3. Экспорт дорожек фоли за тот же диапазон

Тот же диапазон, что и видео:

1. Выделить **все нужные дорожки** и поставить выделение на таймлайне
   **ровно на тот же диапазон** (или просто выделить всё, если сессия короткая).
2. **File → Bounce → Track** — по разу на каждую категорию.
   Или выделить несколько дорожек одной категории и сбаунсить сразу.
3. Параметры: **WAV, 48 000 Гц, 16 или 24 бит**, моно или стерео.
4. Имена — по категориям: `steps.wav`, `hands.wav`, `cloth.wav`, `door.wav`.

> **Важно:** баунсить **дорожку**, а не «Export Clips as Files». Только баунс
> дорожки включает clip gain, громкость и автоматизацию — иначе движок получит
> не то, что слышно в сессии.

> **Преролл:** если хотите дать движку запас по краям (хендлы), добавьте к
> диапазону 1–2 секунды с каждой стороны — но тогда **обязательно скажите**,
> с какого ТК начинается видеофрагмент: смещение движок вычтет сам.

---

## 4. Что передать движку вместе с файлами

Три числа — и всё сходится:

| Что | Где взять | Пример |
| --- | --- | --- |
| **fps** | Setup → Session → Timecode Rate | 25 |
| **ТК начала фрагмента** | позиция курсора в начале выделения | `01:04:12:07` |
| **Session Start** | Setup → Session → Session Start | `01:00:00:00` |

И, если есть, **ваша ручная расстановка** для сверки:
**File → Export → Session Data As Text** — текстом выгрузятся маркеры и позиции
клипов. По ним движок посчитает, где совпал с вами, а где съехал.

---

## 5. Контрольный список

- [ ] Видеофрагмент — mp4, 30–60 с, родной fps
- [ ] Дорожки фоли — WAV 48 кГц, по файлу на категорию, имена = категории
- [ ] Диапазоны видео и звука **совпадают**
- [ ] Записаны три числа: fps, ТК начала фрагмента, Session Start
- [ ] (желательно) экспорт Session Data As Text для сверки

---

## 6. Если что-то не открылось

- **«Не тот формат» при импорте видео** — почти всегда HEVC, ProRes, mkv или
  avi. Конвертируйте в mp4 (H.264) тем же HandBrake.
- **WAV не читается** — проверьте, что это именно WAV, а не, например,
  `AIF` или `SD2`. В Pro Tools при баунсе выберите формат WAV явно.
- **Расстановка уехала на час** — не передан `Session Start`. Самый частый
  случай: сессия начинается с `01:00:00:00`.
