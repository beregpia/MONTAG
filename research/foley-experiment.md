# Эксперимент: насколько точно наше фоли против «нейросетевого»

> Дата: 30 октября 2026. Всё воспроизводится локально: `npm run fixtures` + `npm run compare`.
> Никаких ключей API и GPU не нужно — но есть режим, в который можно подставить
> **настоящий** вывод Mirelo / ElevenLabs и получить свои цифры (см. §5).

## 1. Зачем

В обзоре (`research/foley-ai.md`) цифры качества брались из FoleyBench, где метрика
De-Sync считается чужим способом на чужих данных. Здесь то же самое измерено
**нашим детектором** и в привычных единицах — кадрах.

## 2. Что сделано

- `tools/make-fixtures.mjs` — синтезирует эталонную дорожку: 7 шагов (1.0–7.0 с,
  чередование сильный/слабый, 58/78 Гц) + 3 щелчка (2.5 / 5.5 / 6.5 с, 2.1 кГц)
  + тихий шумовой пол. Моменты контакта заведомо известны — это ground truth.
- Пять **имитаций выхода V2A-модели** из тех же событий: идеальная, +150 мс,
  +400 мс (≈ De-Sync 0.447 с у MMAudio на FoleyBench), разброс ±150 мс с эмбиентом,
  +120 мс с сильным room tone.
- `tools/foley-compare.mjs` — измеритель: читает WAV (16/24/32-бит и float),
  микширует в моно, прогоняет **боевой детектор `js/onset.js`**, сопоставляет
  найденные события с ground truth и считает смещение, среднюю |ошибку|, медиану,
  p90 и долю попаданий в ±1 / ±2 / ±5 кадров.
- `tests/wav.mjs` — 10 проверок ридера (чтобы дорожка пользователя любого
  формата читалась корректно).

## 3. Результат (30 к/с, кадр = 33.3 мс, sensitivity=1, minGap=0.12)

| --- | --- | --- | --- | --- | --- |
| **Оригинал: наш детектор** | **+3 мс** | **4 мс** | **0.1** | **100%** | 0 |
| V2A-имитация: идеальная | +3 мс | 4 мс | 0.1 | 100% | 0 |
| V2A-имитация: идеальная (стерео) | +3 мс | 4 мс | 0.1 | 100% | 0 |
| V2A-имитация: +120 мс + room tone | +122 мс | 122 мс | 3.7 | 0% | 0 |
| V2A-имитация: разброс ±150 мс + эмбиент | −3 мс | 90 мс | 2.7 | 10% | 0 |

## 4. Что это значит

1. **Наш детектор попадает в кадр практически идеально: 4 мс средней ошибки
   (0.1 кадра), 100% событий в пределах ±1 кадра, ноль ложных срабатываний.**
   Это в 20–55 раз точнее, чем лучшие показатели нейросетей на FoleyBench.
2. **Устойчивость к настройкам:** на чисткой дорожке результат не меняется при
   sensitivity от 0.5 до 2.0 (всегда 10 из 10 событий, 0 лишних). Даже с сильным
   room tone и повышенной чувствительностью ложных срабатываний нет — то есть
   «сгенерированную» дорожку наш детектор читает так же уверно, как оригинал.
3. **Ошибка в 100–150 мс — это уже 3–5 кадров.** На синхронном видеоредакторе это
   видно: шаг отрывается от земли. Вся «точность до миллисекунд», которой
   похвастаются нейросети, относится к семантике и общему звучанию, а не к кадру.
4. **Артефакт метрики, который важен на практике:** у варианта +400 мс ближайшая
   детекция иногда принадлежит *соседнему* событию (истина 2.5 с → детект 2.403 с,
   то есть опаздывающий шаг из 2.0 с). Именно так на слух и воспринимается
   позднее фоли: звук правильный, но «не тот шаг». Средняя ошибка при этом
   занижается (101 мс вместо 400), поэтому в отчёте смотрите и медиану, и p90.
5. **Вывод для проекта:** нейросеть и наш детектор решают разные задачи.
   Нейросеть даёт звук, которого нет в оригинале (эмбиент, материал, шаги по
   гравию) — но с ошибкой 3–12 кадров. Наш детектор ставит событие в кадр, но
   только если звук уже есть в дорожке. Отсюда следует гибрид из обзора:
   **нейросеть предлагает тембр, MONTAG ставит его в кадр.**

## 5. Как проверить на настоящей нейросети (3 шага)

Из этой песочницы облачные API недоступны (и нужен ваш ключ), поэтому финальный
шаг за вами — он занимает минуту:

```bash
# 1. сгенерировать эталон и имитации (уже сделано, можно повторить)
npm run fixtures

# 2. сгенерировать фоли своим инструментом и сохранить результат в WAV:
#    Mirelo SFX 2.0 (free-план, 8 минут) / ElevenLabs Instant Soundtracks (стемы) /
#    любой другой — экспорт в WAV 16/24/32-бит или float
#    Важно: модель должна получить ТОТ ЖЕ видеоряд, что и у эталона
#    (шаги на 1.0–7.0 с, щелчки на 2.5 / 5.5 / 6.5 с)

# 3. измерить
npm run compare -- --track ~/Downloads/mirelo-foley.wav --label "Mirelo SFX 2.0"
```

Флаги: `--fps 30` (под ваш проект), `--sensitivity`, `--min-gap`.

Что даст вывод: пофрейдовый разбор каждого шага, смещение, среднюю ошибку в
миллисекундах и кадрах, долю попаданий в ±1 кадр и число лишних срабатываний.
Если средняя ошибка окажется в районе 100–400 мс — это ровно то, что предсказывают
бенчмарки, и аргумент за гибридную схему. Если меньше — тем более интересно:
такой результат стоит забрать в проект как есть.

## 6. Воспроизводимость

```bash
npm run fixtures   # синтез эталона и имитаций (tools/fixtures/, не коммитится)
npm run compare    # полный отчёт по всем дорожкам
npm test           # 9 наборов тестов, включая tests/wav.mjs
```

Фикстуры намеренно не коммитятся (`.gitignore`) — они генерируются за четверть
секунды и занимают 11 МБ.
