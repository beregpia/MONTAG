# Чем питать движок: что подготовить и куда положить

> Дата: 30 октября 2026. Ответ на вопрос «как и куда мне это загружать».
> Здесь — точный список файлов, настройки экспорта из Pro Tools и три способа
> запуска. Первый прогон лучше делать на коротком фрагменте.

---

## 1. Что нужно подготовить (три вещи)

| # | Что | Зачем | Формат |
| --- | --- | --- | --- |
| 1 | **Фрагмент картины** | движок ищет в ней события | mp4 (H.264+AAC) или webm (VP8/VP9) |
| 2 | **Дорожки фоли** — по одному WAV на категорию | источник дублей | WAV 48 кГц, 16 или 24 бит |
| 3 | **Опоры сессии**: fps и стартовый таймкод | чтобы кадры совпали с вашим проектом | просто цифры, их вы знаете |

Плюс, если есть, **ваша ручная расстановка** (маркеры или позиции клипов) —
по ней движок проверит себя: сравнит свой результат с вашим и покажет ошибку
в кадрах. Для первого прогона это самое ценное.

### Имя файла = категория

Движок берёт категорию из имени дорожки, поэтому называйте файлы так, как
названы дорожки в сессии:

```
steps.wav     ← STEP 1, STEP 2, STEP 3 … (можно склеить в одну дорожку)
hands.wav     ← HEANDS1 … HEANDS9
cloth.wav     ← CLOTH 1 … CLOTH 3
door.wav      ← Door, DOOR
requisite.wav ← requisite1 … requisite9
```

Категорий может быть сколько угодно — `metal`, `paper`, что угодно. Список в
коде не зашит, новая категория работает сразу.

## 2. Как выгрузить из Pro Tools

### Дорожки фоли

1. Выделить нужную дорожку (или несколько дорожек одной категории).
2. **File → Bounce → Track** (в старых версиях — Bounce to Disk).
   Важно: именно **bounce дорожки**, а не «Export Clips as Files», потому что
   только баунс дорожки включает clip gain, громкость и автоматизацию.
   Если автоматизации нет — разницы нет.
3. Формат: **WAV, 48 000 Гц, 16 или 24 бит**, моно или стерео — движок читает
   и то, и другое.
4. Сохранить с именем категории.

Если дорожек одной категории много (у вас 9 `STEP`), есть два пути:
- свести их в одну дорожку/файл и дать движку резать её на шаги (удобно, если
  проходы записаны по картинке);
- или оставить отдельными файлами (`steps-1.wav`, `steps-2.wav` …) — тогда
  движок будет выбирать между вариантами и не повторит один и тот же шаг подряд.

### Опоры сессии

**Setup → Session** (или Ctrl+2):
- **Timecode Rate** — это fps (24, 25 или 30). Нужен ровно тот, что в проекте.
- **Session Start** — стартовый таймкод. Если он `01:00:00:00`, а не
  `00:00:00:00`, обязательно скажите: иначе все позиции поедут на час.

### Ваша ручная расстановка (для проверки)

**File → Export → Session Data As Text** — выгружает состав сессии текстом,
включая маркеры и позиции клипов. Этого достаточно, чтобы движок сравнил свой
результат с вашим и посчитал ошибку в кадрах.

## 3. Куда загружать — три способа

### Способ 1. Прислать файлы сюда (проще всего)

Приложите файлы к сообщению так же, как присылали скриншоты. Я прогоню
конвейер и верну:
- таблицу расстановки «кадр → откуда резать»;
- готовые файлы для импорта в Pro Tools (маркеры и/или AAF);
- сравнение с вашей ручной расстановкой, если пришлёте её.

**Ограничение по размеру:** большой фрагмент может не пройти. Для первого
прогона берите **30–60 секунд** и 2–3 дорожки. Ориентир:
- видео 60 с в 1080p — примерно 10–50 МБ;
- одна дорожка 60 с, 48 кГц, 24 бит, моно — около 8.6 МБ.

### Способ 2. Запустить у себя

Нужен Node.js (один установщик, бесплатно, VS Code не нужен):

```bash
# один раз
node --version          # проверка, что установился

# получить проект
git clone -b arena/c575b8e1-montag https://github.com/beregpia/MONTAG.git
cd MONTAG
npm install

# прогнать демо-конвейер целиком
npm run place-demo

# на своих файлах: проиндексировать каждую дорожку своей категорией
node tools/foley-library.mjs --track steps.wav --category steps --min-gap 0.3
node tools/foley-library.mjs --track hands.wav --category hands --min-gap 0.12

# сопоставить с картинкой
node tools/place-foley.mjs --library . --video events.json
```

Или скачать архив без git:
`https://github.com/beregpia/MONTAG/archive/refs/heads/arena/c575b8e1-montag.zip`

### Способ 3. В браузере, двойным щелчком (в разработке)

Открыть `montag-standalone.html` и перетащить файлы в окно — без установки
Node, без консоли. Сейчас в приложение встроены импорт видео и синтез звука;
конвейер размещения (индексация дорожек → события на картинке → расстановка)
переносится в него следующим шагом.

## 4. Какой фрагмент лучше взять первым

Не самый красивый, а **самый проверяемый**:

1. **30–60 секунд**, где есть ходьба — шаги видны и их легко сверить.
2. **2–3 дорожки** (`steps` + `hands`, при наличии `cloth`).
3. **Та сцена, которую вы уже расставили руками** — тогда я посчитаю, где
   движок совпал с вами, где съехал на шаг, и на сколько кадров.
4. **Без резких смен планов** — на первый прогон возьмём один непрерывный план.

Из такого фрагмента получится честная цифра: «движок закрыл N из M контактов,
совпал с вашей расстановкой в X% в пределах одного кадра». Дальше уже можно
брать полнометраж.

---

## 5. Чего пока не хватает (чтобы не было сюрпризов)

- **События на картинке движок ещё не ищет** — видео-детектор в разработке.
  Поэтому для первого прогона события можно задать вашими маркерами или
  разметкой вручную, а детектор я доведу параллельно. Без этого входа
  расстановка не запустится — это единственное недостающее звено.
- **90 минут за раз** — конвейер считает быстро (аудио в 80 раз быстрее
  реального времени), но для проверки лучше нарезать материал на сцены.
- **mkv, ProRes, HEVC, avi** браузер не откроет — конвертируйте в mp4
  (HandBrake или ffmpeg). WAV конвертировать не нужно никогда.
