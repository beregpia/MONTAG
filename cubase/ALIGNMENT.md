# Синхронизация фоли по дорожкам в Cubase

Руководство по выравниванию отдельно записанных фоли-дорожек (шаги, руки,
предметы) относительно видео — с маркерами, которые генерирует MONTAG.

> **Почему не плагин и не скрипт.** VST3 — аудиопроцессор: он обрабатывает
> только свой поток и физически не может двигать клипы на других дорожках.
> В Cubase нет публичного скриптового API для аранжировки (MIDI Remote API
> работает лишь с контроллерами и микшером; пресеты Project Logical Editor
> нельзя редактировать вручную). Поэтому рабочий путь в Cubase —
> **маркеры + привязка (Snap)**, а позиции маркеров считает наш детектор.

---

## Схема

```
MONTAG:  видео → Foley → Анализировать аудио → Экспорт маркеров (.mid)
                        ↓
Cubase:  File → Import → MIDI File   (маркеры становятся маркерами проекта)
                        ↓
Cubase:  Snap = Events → перетаскивание фоли-событий к маркерам
```

Маркеры пишутся в Standard MIDI File с темпомапой **1 тик = 1 мс**
(PPQ 480, 125 BPM), поэтому позиции попадают в проект с точностью до 1 мс —
это ~1/33 кадра при 30 fps.

---

## Шаг 1. Подготовка проекта в Cubase

1. Импортируйте видео (`File → Import → Video File`) на видеодорожку.
2. Переключите **вторичный дисплей транспорта на Timecode** — при работе
   с картинкой секунды+кадры удобнее, чем такты+доли.
3. Установите фпс проекта равным фпсу видео
   (`Project → Project Setup → Frame Rate`) — иначе «кадр» в Cubase
   и в вашем исходнике будут разной длительности.
4. Разложите фоли-записи по отдельным дорожкам: одна дорожка — один
   тип звука (шаги / одежда / предметы). Длинные записи не режьте заранее.

## Шаг 2. Маркеры из MONTAG

1. Импортируйте то же видео в MONTAG (драг-н-дроп или «＋ Импорт видео»).
2. Откройте панель **🎙 Foley** → выберите файл-источник → **«Анализировать
   аудио»**. Подберите «Порог детекта» и «Мин. интервал»: шаги обычно
   ловятся при чувствительности около 1.0 и интервале 120–200 мс,
   тихие шелесты — при более низком пороге.
3. Нажмите **«⇩ Экспорт маркеров в MIDI (.mid)»**.
   - *Найденные события источника* — маркеры по всем моментам контакта
     в звуке видео (основной режим).
   - *Размещённые фоли-события* — маркеры по уже размещённым в MONTAG
     фоли-событиям, с учётом ваших покадровых сдвигов.
   - **Смещение, с** — если видео в проекте Cubase стоит не с нуля
     (например, с 00:00:10:00), укажите здесь этот сдвиг.
4. Проверьте имена маркеров в имени файла: `montag-markers-<имя видео>.mid`.
   Внутри — маркеры вида `01 0.60s low step` (время, диапазон, звук).

> Альтернатива без MONTAG: откройте звук видео в Sample Editor →
> Inspector → **Hitpoints** → Create → **Markers**. Cubase создаст маркеры
> по своим хитпоинтам. Способ работает, но MONTAG даёт классификацию
> по диапазонам (шаги/ткань/щелчки) и экспорт сразу пачкой.

## Шаг 3. Импорт маркеров в Cubase

1. `Preferences → MIDI → MIDI File` → включите **Import Markers**.
   Без этой галочки маркеры молча пропадут.
2. `File → Import → MIDI File` → выберите `.mid`.
   Если проект уже открыт, ответьте **No** на вопрос о создании нового
   проекта (маркеры добавятся в текущий).
   Самый надёжный способ — **перетащить `.mid` мышью в окно проекта**.
3. Маркеры появятся на маркерной дорожке. Если её не было — Cubase
   создаст её автоматически.

## Шаг 4. Настройка привязки

1. Включите **Snap** (кнопка на панели инструментов проекта).
2. Тип привязки — **Events**. В этом режиме магнитятся:
   - начала и концы других событий,
   - **внутренняя точка привязки (snap point) аудио-события**,
   - **маркеры** на маркерной дорожке.
3. Включите **Snap to Zero Crossing** (тулбар / `Preferences → Editing → Audio`) —
   чтобы при перетаскивании не появлялись щелчки на срезах.
4. Выставите зум так, чтобы были видны и маркер, и событие.

## Шаг 5. Выравнивание дорожек

Два способа — выбирайте по ситуации.

### Способ А. По началу события (звук начинается ровно в начале клипа)

Перетащите начало фоли-события так, чтобы оно замагнилось к нужному маркеру.
Подходит, когда запись сделана «с чистого листа» и каждый звук — отдельный
файл/событие.

### Способ Б. По внутренней точке (звук где-то внутри длинного клипа)

Так выравнивают запись, снятую цепочкой: шаги, шуршание, удары — всё в одном
проходе.

1. Откройте фоли-событие в **Sample Editor** (двойной клик).
2. Найдите нужный транзиент (щипок/шаг) — прослушайте окрестности.
3. Поставьте **курсор проекта точно на транзиент** (в Sample Editor курсор
   виден и там, и в проекте).
4. `Audio → Snap Point to Cursor`. В событии появится вертикальная линия
   точки привязки.
5. В окне проекта перетащите событие к нужному маркеру — магнититься будет
   **именно внутренняя точка**, а не начало клипа.
6. Повторите для каждого звука в записи.

> Совет: если событие нужно сдвинуть целиком вместе с точкой привязки —
> тяните за тело события, а не за края (края меняют длительность).

## Шаг 6. Тонкая подгонка

- **Info Line**: кликните по полю Start и введите позицию вручную —
  в сэмплах (если линейка в Samples) или в таймкоде. Это самый точный способ.
- **Nudge**: `Ctrl/Cmd + ←/→` сдвигает выделенные события на заданный шаг
  (величина шага настраивается в `Preferences → Editing`).
- **Q** (Quantize) двигает событие так, чтобы его точка привязки встала
  на ближайшую линию сетки — удобно, если маркеры стоят по сетке.
- **Shift + перетаскивание** ограничивает движение одной осью.

## Шаг 7. Массовый сдвиг выделенных событий (Project Logical Editor)

Если группа событий смещена на одно и то же значение (например, вся дорожка
опаздывает на 2 кадра):

1. Выделите события.
2. `Edit → Project Logical Editor`.
3. В **Event Target Filters** задайте условие отбора (например,
   *Container Type is equal to Event* — тогда фильтр не тронет партии).
4. В **Event Transform Actions** добавьте действие с целью **Position**
   и нужным сдвигом.
5. Примените, затем **сохраните как пресет** («Save Changes as Preset»).
6. Пресету можно назначить горячую клавишу:
   `Edit → Key Commands` → категория **Process Logical Preset**.

> Пресеты PLE — бинарные/защищённые файлы, сгенерировать их текстом нельзя,
> поэтому настройка делается вручную один раз.

## Шаг 8. Проверка

- `S` — solo дорожки фоли, прослушайте в паре с видео.
- Сравните «до/после»: времено отключите дорожку (`M`).
- Смотрите на форму волны: транзиент фоли должен совпадать с маркером
  по глазкомеру, а не «примерно рядом».
- Если слышите разрыв в начале звука — вернитесь к **Snap to Zero Crossing**
  и/или добавьте кроссфейд (`X`) между соседними событиями.

## Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| Маркеры не появились после импорта | Не включён `Preferences → MIDI → MIDI File → Import Markers` |
| Маркеры есть, но события не магятятся | Тип Snap не `Events`, либо Snap выключен |
| Магнитится начало клипа, а не транзиент внутри | Не задана точка привязки: `Audio → Snap Point to Cursor` |
| Маркеры смещены на постоянную величину | Видео в проекте не с нуля — укажите «Смещение» при экспорте в MONTAG |
| Точность 1 мс недостаточна | Доводите позицию вручную в Info Line (сэмплы) |
| Звук «щелкает» на резах | Включите Snap to Zero Crossing, либо сдвиньте на несколько сэмплов |

## Если нужна автоматическая выравнивание

Полностью автоматический перенос событий (детект → сдвиг каждого события →
экспорт свёденного звука) в Cubase невозможен без сторонних инструментов
вроде Revoice Pro / Melodyne ARA. Эту часть закрывает браузерный редактор
**MONTAG**: он считает те же моменты контакта, сам расставляет фоли-события
на таймлайне с покадровой подгонкой и экспортирует готовое видео со звуком —
а маркеры из него пригодятся, когда финальная сборка идёт в Cubase.
