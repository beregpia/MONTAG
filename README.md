# MONTAG

Видеомонтажёр, который работает целиком в браузере: импорт клипов, таймлайн,
подрезка, переходы, превью в реальном времени и экспорт готового ролика в `.webm`.
Ничего не загружается на сервер — файлы остаются на вашем компьютере.

## Запуск

```bash
node server.js
# или
npm start
```

Затем открыть http://localhost:8080

## Возможности

- **Импорт** — перетащите видео в окно или нажмите «Импорт видео» (mp4, webm, mov).
  Двойной клик по файлу в медиатеке добавляет его на таймлайн.
- **Таймлайн** — клипы выстраиваются в последовательность, перетаскиваются
  мышью для смены порядка, удаляются кнопкой или клавишей `Delete`.
  Зум `＋ / −`, клик по линейке — переход к позиции.
- **Подрезка** — в инспекторе справа задаются точки «Начало» / «Конец» клипа.
- **Переходы** — между клипами: без перехода, кроссфейд или «через чёрный».
- **Звук** — громкость каждого клипа + общая мастер-шина (Web Audio).
- **Разделение** — кнопка «✂ Разделить» или клавиша `S` режет клип
  в позиции playhead.
- **Экспорт** — кнопка «⏺ Экспорт видео» собирает ролик в `.webm`
  (VP9/VP8 + Opus) и скачивает его. Запись идёт в реальном времени,
  поэтому ролик длиной 1 минута экспортируется ~1 минуту.
- **Проект** — «Проект ↓ / ↑» сохраняет и открывает монтаж в JSON
  (видео нужно импортировать повторно — файлы не хранятся внутри проекта).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | пуск / пауза |
| `S` | разделить клип в позиции playhead |
| `←` / `→` | ±1 с (`Shift` — ±5 с) |
| `Home` / `End` | в начало / в конец |
| `Delete` | удалить выбранный клип |

## Технологии

Чистый фронтенд без сборки и зависимостей: ES-модули, Canvas 2D,
Web Audio API, `canvas.captureStream()` + `MediaRecorder`.
Рекомендуемые браузеры — Chrome, Edge или Firefox.

## Структура

```
index.html        — разметка интерфейса
css/style.css     — оформление (тёмная тема)
js/state.js       — состояние проекта, раскладка таймлайна, шина событий
js/media.js       — импорт файлов, превью-кадры, медиатека
js/timeline.js    — дорожка, плейхед, drag & drop, зум
js/inspector.js   — параметры выбранного клипа
js/player.js      — движок превью: композитинг кадров и аудиограф
js/recorder.js    — экспорт в .webm
js/project.js     — сохранение / открытие проекта (JSON)
js/main.js        — точка входа
server.js         — статический сервер для разработки
```
