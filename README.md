# MONTAG

Видеомонтажёр, который работает целиком в браузере: импорт клипов, таймлайн,
подрезка, переходы, превью в реальном времени и экспорт готового ролика в `.webm`.
Ничего не загружается на сервер — файлы остаются на вашем компьютере.

## Запуск

```bash
node server.js
# или
npm start
```

Затем открыть http://localhost:8080

## Возможности

- **Импорт** — перетащите видео в окно или нажмите «Импорт видео» (mp4, webm, mov).
  Двойной клик по файлу в медиатеке добавляет его на таймлайн.
- **Таймлайн** — клипы выстраиваются в последовательность, перетаскиваются
  мышью для смены порядка, удаляются кнопкой или клавишей `Delete`.
  Зум `＋ / −`, клик по линейке — переход к позиции.
- **Подрезка** — в инспекторе справа задаются точки «Начало» / «Конец» клипа.
- **Переходы** — между клипами: без перехода, кроссфейд или «через чёрный».
- **Звук** — громкость каждого клипа + общая мастер-шина (Web Audio).
- **Разделение** — кнопка «✂ Разделить» или клавиша `S` режет клип
  в позиции playhead.
- **Экспорт** — кнопка «⏺ Экспорт видео» собирает ролик в `.webm`
  (VP9/VP8 + Opus) и скачивает его. Запись идёт в реальном времени,
  поэтому ролик длиной 1 минута экспортируется ~1 минуту.
- **Проект** — «Проект ↓ / ↑» сохраняет и открывает монтаж в JSON
  (видео нужно импортировать повторно — файлы не хранятся внутри проекта).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | пуск / пауза |
| `S` | разделить клип в позиции playhead |
| `←` / `→` | ±1 с (`Shift` — ±5 с) |
| `Home` / `End` | в начало / в конец |
| `Delete` | удалить выбранный клип |

## 🎙 Foley — синхронизация звука с видео

Кнопка **🎙 Foley** в верхней панели открывает панель фоли-озвучки: шаги, руки,
предметы и другие шумы контакта, синхронизированные с картинкой.

**Как работает:**

1. **Анализ** — выберите файл-источник и нажмите «Анализировать аудио».
   Звуковая дорожка декодируется и прогоняется через детектор моментов
   контакта: STFT (собственная FFT, окно Ханна) → спектральный флюкс →
   пики с адаптивным порогом. Каждое событие классифицируется по диапазону:
   `низкий` (шаги, удары, предметы), `средний` (ткань, взмахи), `высокий`
   (щелчки, пластик). Ползунки «Порог детекта» и «Мин. интервал» пересчитывают
   анализ на лету.
2. **Перенос** — «Перенести события на таймлайн» расставляет фоли-события
   с учётом in-точек клипов (если клип обрезан, события внутри обрезки
   не попадают) и авто-подбирает звук по диапазону и силе.
3. **Подгонка** — у каждого события: выбор звука из библиотеки, сдвиг
   **на кадр** кнопками `−1к / +1к` (точность = 1/fps, по умолчанию 33 мс
   при 30 fps), громкость, прослушивание в контексте таймлайна.
   События-маркеры видны на отдельной дорожке под клипами.
4. **Микшер** — общая громкость фоли-шины; при экспорте фоли-звук
   попадает в запись автоматически (шина подключена к мастер-каналу).

**Библиотека звуков** синтезируется процедурно (шум + однополюсные фильтры +
синусы с огибающими) — внешние сэмплы не нужны: шаг, тихий шаг, каблук,
туду, ткань/руки, шелест, касание, взмах, клик, металл/пластик. При
   срабатывании к каждому звуку применяется лёгкая вариация темпа, чтобы
   серия шагов не звучала «заедающим» сэмплом.

**Синхронизация:** триггер срабатывает в кадре, где playhead пересекает время
   события; задержка кадра (~16 мс) компенсируется смещением внутрь буфера
   звука, так что попадание практически покадровое. Перескоки (seek) не
   запускают всю серию звуков подряд.

**Ограничения:** браузер должен уметь декодировать аудио из вашего файла
   (mp4/AAC, webm/Opus — обычно умеют). Анализ файлов >200 МБ может занять
   десятки секунд. Экспорт фоли идёт в реальном времени вместе с роликом.

## Технологии

Чистый фронтенд без сборки и зависимостей: ES-модули, Canvas 2D,
Web Audio API, `canvas.captureStream()` + `MediaRecorder`.
Рекомендуемые браузеры — Chrome, Edge или Firefox.

## Структура

```
index.html        — разметка интерфейса
css/style.css     — оформление (тёмная тема)
js/state.js       — состояние проекта, раскладка таймлайна, шина событий
js/media.js       — импорт файлов, превью-кадры, медиатека
js/timeline.js    — дорожка, плейхед, drag & drop, зум, дорожка фоли
js/inspector.js   — параметры выбранного клипа
js/player.js      — движок превью: композитинг кадров и аудиограф
js/recorder.js    — экспорт в .webm
js/project.js     — сохранение / открытие проекта (JSON)
js/main.js        — точка входа
js/fft.js         — быстрое преобразование Фурье (radix-2)
js/onset.js       — детект моментов контакта (spectral flux)
js/sfx.js         — процедурный синтез фоли-звуков
js/foley.js       — фоли-движок: анализ, размещение, триггеры
js/foley-panel.js — панель Foley
server.js         — статический сервер для разработки
```
